      Updates

      The app checks GitHub for a new version every time it opens and installs it automatically. Only the latest version number is fetched; nothing about your usage is sent.

      Track any other AI

      Log usage from any AI tool or script. It shows up here like the built-in tools.

      ai-tokens --add ChatGPT gpt-5 1200 350 --prompt "draft email"
      from ai_token_tracker import log_usage
log_usage("My app", r.model, r.usage.input_tokens, r.usage.output_tokens)

      Or drop a CSV with timestamp, tool, model, input_tokens, output_tokens into the custom log folder listed on the left.

      Privacy

      Everything stays on this computer. The tracker only reads the log files your AI tools already write, and this page is served from your own machine.

      It connects to the internet only to check GitHub for app updates, to ask Anthropic for your Claude plan usage (if Claude Code is logged in), and, when you click it, to download the latest prices.
